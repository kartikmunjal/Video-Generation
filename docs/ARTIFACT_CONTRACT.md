# Artifact contract

Each confirmatory augmentation arm must record parent artifact hashes, source
lineage, all generated candidate specifications, selected candidate IDs, reward
checkpoint hash, exact examples and optimizer steps, raw test predictions,
resource telemetry, and generated metrics with `N_trials` and 95% confidence
intervals. Missing or unequal budgets invalidate the comparison.

Exploratory CogVideoX artifacts may not be promoted without their own frozen
extension protocol and independent evaluation channel.

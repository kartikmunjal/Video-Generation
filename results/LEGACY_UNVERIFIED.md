# Legacy unverified artifacts

The JSON files under `annotation_study/` and `iterative_dpo/` predate the frozen
UCF-101 research program. They are retained for provenance only. Their numbers
must not be cited, graphed as findings, or used in a job application because the
repository does not contain the raw videos, checkpoints, logs, or annotation
rows required to regenerate them.

Confirmatory artifacts must live in a study-ID directory, include input and
checkpoint hashes, raw predictions, per-run manifests, `N_trials`, and 95%
confidence intervals, and pass the corresponding `RESEARCH_PLAN.md` gates.

# Confirmatory report: reward-guided video augmentation

This report is generated by `scripts/publish_confirmatory_report.py` from raw selection, prediction, and run artifacts; displayed values are not hand edited.

## Design

The experiment selected one augmentation for each of 7,575 training sources across three official UCF-101 splits. Four arms used identical unique sources, example counts, feature extractor, classifier settings, and optimization seeds. The untouched official test sets contain no selection inputs.

Uncertainty uses 2,000 deterministic paired hierarchical-bootstrap replicates (`N_trials=3`, `N_optimization_seeds=3`). Holm adjustment covers the two confirmatory downstream outcomes.

The parent-matched `lbfgs` classifier is deterministic: 0 split×arm×video predictions varied across the three requested seed labels. The seed runs are reproducibility repeats, not independent trials; inferential replication comes from the three official splits.

## Confirmatory outcomes

- Guided minus random macro recall: **0.114 pp [-0.227, 0.518]**, Holm-adjusted `p=0.568`.
- Guided minus random worst-decile recall: **1.528 pp [-0.236, 3.233]**, Holm-adjusted `p=0.216`.
- Guided rejection-to-clean-duplicate rate: **42.53% [41.06%, 44.01%]**.

The study did not establish that reward guidance improves macro recall over random augmentation under the frozen budget.

Across 303 split-by-class cells, the association between the guided-minus-random predicted-damage gap and downstream error change was Spearman **-0.015 [-0.120, 0.097]**. This is a mechanism check, not a causal estimate beyond the randomized policy comparison.

## Evidence boundary

The parent reward model was validated on controlled synthetic interventions and showed a retained leave-family-out temporal failure. This downstream study tests a fixed mild candidate set; it does not validate human preference, text-to-video generation, DiffusionDPO, or unrestricted reward optimization.

The first execution stopped before producing a selection because H.264 macroblock padding made the pixel-MSE diagnostic grids unequal. The linked implementation note records the pre-outcome implementation corrections.
